# Systems, software, and stray signal

Montreal-based software developer who thinks in systems — digital, organizational, and occasionally constitutional. I write about all three at obscuretone.com.

Things I build:

🎮 Game Boy internals — a Python emulator (pygameboy), a self-checking DMG opcode test ROM, and a Python REPL that runs inside a Game Boy ROM, because someone had to

🤖 Tools for humans and agents — nira, an issue tracker with a CLI built for agentic AI workflows

✅ The same TODO app, repeatedly — Sanic, Spring Boot + Oracle, RoadRunner, Go + Neo4j, MongoDB + TypeScript, mainframe. It's not indecision; it's a benchmark of ecosystems (and of my patience)

📉 Satire that compiles — a 100% accurate productivity monitor intended to replace JIRA, and an implementation of the classic XKCD "tasks" comic

I'm interested in the gap between how systems are supposed to work and how they actually do — whether that system is a CPU, a hiring pipeline, or a country.
